# Anemone - HealthTech UI/UX & Emotional Wellbeing Platform

Anemone is an empathetic, AI-powered HealthTech web interface designed for emotional containment and mental health guidance. This project showcases the complete workflow from custom vector design to clean front-end implementation.

## Key Features
- **Empathetic UI/UX Design:** User-centric, clean interface built to foster trust, calmness, and safety.
- **Interactive Media Player:** Custom JavaScript controls for video streaming and audio management.
- **Responsive Toolbar & App Previews:** Modern UI components and mobile application mockups.
- **Design System Integration:** Built in strict alignment with the Anemone Brand Identity System (accessibility-first color palette, typography hierarchy, and visual spacing).

## Visual Identity & Workflow
- **Design & Mockups:** Crafted entirely from scratch using **Adobe Illustrator** (vector SVG assets, layout mockups, and exported PNG graphics).
- **Comprehensive Brand Manual:** Based on a 55-page corporate design system covering logo architecture, color theory, and UI specifications.
- **Color Palette:** Hex `#3BA9E0` (Cyan), `#EAA2B8` (Soft Pink), `#E6007E` (Magenta), `#54C5D0` (Teal), and `#838BC5` (Lavender).
- **Typography:** Givonic Demo (Headings), Calibri (UI Body), and Aliens and Cows (Accents).

##  Tech Stack & Tools
- **UI/UX & Vector Design:** Adobe Illustrator (SVG / PNG exports)
- **Code Editor:** Visual Studio Code
- **Frontend Development:** HTML5, CSS3, Modern JavaScript (ES6+)
